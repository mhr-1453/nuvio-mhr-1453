# mhr-1453'ün Deposu

Nuvio uygulaması için Türkçe içerik eklentileri.

## Kurulum

1. Nuvio uygulamasını açın.
2. **Ayarlar → İçerik & Keşif → Pluginler** bölümüne gidin.
3. **Repository** alanına şu adresi ekleyin:

   ```
   https://raw.githubusercontent.com/mhr-1453/nuvio-mhr-1453/refs/heads/main/manifest.json
   ```

4. Depo yüklendikten sonra listeden istediğin eklentiyi açın.

## Eklentiler

| Eklenti | Kaynak site | İçerik | Biçim |
| --- | --- | --- | --- |
| **AnimeciX** | animecix.tv | Anime (Türkçe altyazılı + dublaj) | MP4, m3u8 |
| **SuperFilmIzle** | superfilmizle2.icu | Film, dizi, anime (Türkçe) | m3u8 |
| **FilmIzyon** | filmizyon.net | Film, dizi, anime (Türkçe) | m3u8 |
